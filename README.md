# TigerDC++ feedback

Bug reports and feature requests for TigerDC++, a Direct Connect client for Mac.

- [Report a bug](https://github.com/pinemoonstudios/tigerdc-feedback/issues/new?template=bug_report.yml)
- [Suggest an improvement](https://github.com/pinemoonstudios/tigerdc-feedback/issues/new?template=feature_request.yml)
- [Search existing reports](https://github.com/pinemoonstudios/tigerdc-feedback/issues)

English and Russian are welcome. Include your app version, macOS version and steps to reproduce the problem. Screenshots help; please remove private details first.

Issues are public. For purchases, license activation or security-sensitive reports, email **pinemoonstudios@gmail.com**. Never post license keys, passwords, private messages or file lists.

This repository contains feedback, not application source code or downloads. A report is closed after the fix is released, with the version noted in the issue.

## По-русски

Здесь можно сообщить об ошибке или предложить улучшение TigerDC++. Пишите на русском или английском. Укажите версию приложения и macOS, опишите, как повторить проблему.

Обращения видны всем. По вопросам покупки, лицензии и безопасности пишите на **pinemoonstudios@gmail.com**. Не публикуйте ключи, пароли, личную переписку и списки файлов.
